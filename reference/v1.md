# MarkdownPoint file format reference

Generated from MarkdownPoint's source at 096ded2f. It lists every key in the files and what it does.

Each key belongs to one category:

- **Design**: type, color, layout and effects
- **Motion and media**: time, motion and media
- **Presentation**: what only a presentation has, such as when a step starts and slide transitions
- **File**: the file's own bookkeeping

A canvas unit is one pixel of the slide at full size. A length is kept to a millionth of one. A color is a hex color or a role in the design's color scheme, such as accent. A hex color is in sRGB, written as CSS writes it: #RGB, #RGBA, #RRGGBB or #RRGGBBAA. Its alpha is straight, not premultiplied.

An object's font size, insets, corner radius, strokes, text spacing and flat depth each reach at most 33,554,431.984375 canvas units. That is (2³¹ − 1) / 64, the longest length Chromium lays out. Text flows into at most 65,535 columns.

The 3D layer is lit in linear light. It is tone-mapped with Khronos PBR Neutral at an exposure of 1 and written in sRGB, the color space of the slide's flat colors. A camera's lens is measured on a 36 mm film across the slide's longer side, as Blender's Sensor Fit Auto measures it. A World with no color lights the 3D layer with `environments/studio.hdr`, an equirectangular Radiance HDR file whose SHA-256 is ce14a3984f83a8d231cad84cddc9ede84c73743d6d7956daf209f62e1afd1282.

A 1.x app opens a later 1.x file read-only where it holds what the app doesn't know, so the app never writes it away.

Another tool may add keys of its own to the presentation, a slide, a composition, an override, an object or a design file. Each starts with x-. MarkdownPoint keeps them and ignores them.

### transition

A slide transition. A scroll moves both slides along one strip. Each slide's 3D keeps its place in the slide's stacking order, clipped at the slide's edge, and a model or 3D text the two slides share by id crosses the seam whole. Neither slide's camera drifts. At `transition, slides.<id>.transition`.

| key | values | category | description |
| --- | --- | --- | --- |
| `effect` | none, cross-dissolve, carry-over, push, scroll, move-in, reveal, wipe, zoom, fade-through-color | presentation | Which transition plays, or none. |
| `duration` |  | motion | How long it takes, in seconds. |
| `easing` | linear, ease-in, ease-out, ease-in-out | motion | How the objects Carry over moves, or the strip a scroll travels, speed up and slow down. |
| `match` | object, word, character | presentation | What Carry over matches between two texts: whole objects, words or characters. |
| `direction` | left, right, up, down | presentation | Which way a push, scroll, move in, reveal or wipe travels across the screen. |
| `color` |  | presentation | The color of a fade through color: a color role or a hex color. |
| `start` | automatically | presentation | When it starts: automatically after the slide's last build, or on a click when left out. |
| `delay` |  | motion | For a transition that starts by itself, the seconds it waits after the slide's last build ends. |

# MarkdownPoint file format reference

Generated from MarkdownPoint's source at 84541813. It lists every key in the files and what it does.

Each key is named the way the products in its category name it:

- **Design**: Figma, InDesign, Illustrator
- **Motion and media**: After Effects, Final Cut Pro
- **Presentation**: Keynote, PowerPoint
- **File**: none; these keys are the file's bookkeeping

A canvas unit is one pixel of the slide at full size. A color is a hex color or a role in the design's color scheme, such as accent.

## <a id="presentation-md"></a>presentation.md

In presentation.md: [frontmatter](#frontmatter) · [markers](#markers) · [body](#body) · [markdown](#markdown)

### frontmatter

The keys MarkdownPoint reads, each on one line as key: value. Other keys are kept as written. At `the frontmatter at the top`.

| key | values | category | description |
| --- | --- | --- | --- |
| `markdownpoint` |  | file | The format version, 1. |
| `document` |  | file | The presentation's id, the same as presentation.json's. |
| `footer` |  | presentation | The footer text, shown on every slide with a footer field. |
| `save` |  | file | The same id as presentation.json's save, written by the last save before another person takes over editing. |

### markers

The markers that divide presentation.md into sections, slides and their text. At `a line of its own in the body`.

| key | values | category | description |
| --- | --- | --- | --- |
| `section` |  | presentation | `<!-- section: id -->` opens a section. The heading after it is the section's name. |
| `slide` |  | presentation | `<!-- slide: id -->` opens a slide, in presentation order. |
| `composition` |  | motion | `<!-- composition: id -->` opens a composition's text. |
| `text` |  | presentation | `<!-- text: id -->` starts an object's text, or a composition instance's text control as `instance.control`. |
| `control` |  | motion | `<!-- control: name -->` starts the default text of a composition's text control. |
| `notes` |  | presentation | `<!-- notes -->` starts the slide's speaker notes. |

### body

How the body is divided, and what is kept as written. At `the body, between and inside the markers`.

| key | values | category | description |
| --- | --- | --- | --- |
| `separator` |  | presentation | A line of `---` ends a slide before the next slide's marker, with only blank lines and comments between them. |
| `escape` |  | file | A backslash before a line that looks like a marker or a separator makes it plain text. |
| `comment` |  | file | Any other HTML comment is a note. It's kept in the file and not shown on slides. |
| `unsupported` |  | file | Markdown that MarkdownPoint doesn't support, such as a picture or an HTML tag, is kept as written and shown as plain text. |

### markdown

The Markdown that text, tables and speaker notes use. At `text blocks, table cells and speaker notes`.

| key | values | category | description |
| --- | --- | --- | --- |
| `paragraph` |  | design | Lines separated by a blank line are paragraphs. |
| `heading` |  | design | `# Heading` to `###### Heading` are headings. Under a section marker, the heading is the section's name. |
| `list` |  | design | Lines starting with `- ` are a bulleted list. Indent for deeper levels. |
| `numbered-list` |  | design | Lines starting with `1. ` are a numbered list. It can start at any whole number from 0. |
| `quote` |  | design | Lines starting with `> ` are a quote. |
| `code-block` |  | design | Lines between ``` fences are a code block, with an optional language after the opening fence. |
| `rule` |  | design | A line of `***` is a horizontal rule, and so is `---` when more of the block's text follows. |
| `table` |  | design | A table's text is a Markdown table: a header row, a divider row and body rows, with `\|` between cells. |
| `bold` |  | design | `**text**` is bold. |
| `italic` |  | design | `*text*` is italic. |
| `highlight` |  | design | `==text==` is highlighted. |
| `strikethrough` |  | design | `~~text~~` is struck through. |
| `code` |  | design | `` `text` `` is code. |
| `link` |  | presentation | `[text](address)` links to a webpage, an email or phone address, or a slide as `slide:id`. |
| `color` |  | design | `[text]{color=accent}` or `[text]{color="#2F7D4F"}` colors text with a color role or a hex color. |
| `field` | slide-number, slide-count, section-number, section-name, date, footer | presentation | `{{name}}` shows a value the presentation fills in. |
| `line-break` |  | design | A backslash at the end of a line breaks the line within its paragraph. Inside colored text or a link's text, the break is written `<br>`. |
